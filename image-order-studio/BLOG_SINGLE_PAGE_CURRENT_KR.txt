[무료 배포 / 개발 중] Image Order Studio — 이미지 업로드 순서를 지정하고 보존하는 갤러리

AI와 리뷰 사이트에 여러 장의 이미지를 올리면 순서가 제멋대로 바뀌는 문제를 해결하기 위해 만든 Android 앱입니다.

갤러리에서 이미지를 가져와 원하는 순서대로 탭하면 1·2·3 순번이 붙습니다. 이후 해당 순번을 이미지에 직접 넣은 JPG/PNG로 공유하거나, 한 장으로 결합하거나, 저장된 폴더에서 직접 첨부할 수 있습니다. 외부 사이트가 파일을 재정렬해도 이미지에 기재된 원래 순서를 확인할 수 있습니다.

광고·회원가입·인터넷 권한 없이 로컬에서 실행합니다. 원본 이미지는 변경하지 않습니다.

※ GitHub의 공개 베타 다운로드 주소는 계속 유지합니다. 외부 웹사이트의 첨부 표시 순서는 앱이 제어하지 않으며, 이미지에 직접 기록된 번호 또는 합친 이미지가 최종 순서를 전달합니다.
