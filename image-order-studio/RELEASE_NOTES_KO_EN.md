# Image Order Studio — 공개 베타 v0.2.0 (2bornot)

- 개발자: **2bornot** / Android 8.0 이상 / 한국어·영어 UI
- 다운로드: `ImageOrderStudio.apk` — Android에 설치 가능한 **정식 릴리스 서명 APK**. 소스 및 SHA-256 파일도 제공.
- 갤러리/파일 탐색기에서 이미지를 가져온 뒤 앱 안에서 차례대로 탭하여 명시적으로 순번을 지정합니다. 가져온 파일 이름·확장자·폴더 정렬·사진 제공자 반환 순서는 기준이 아닙니다.
- 외부 사이트가 순서를 섞어도 이미지 자체에서 순번을 알아볼 수 있도록 번호 삽입 JPG/PNG를 제공합니다. 저용량 JPG, PNG, 하나로 결합, 순서 목록 복사, 선택 순서 편집, 선택한 이미지만 보기, 선택한 이미지 우선 정렬을 지원합니다.
- 로컬 처리. 광고·계정·추적·인터넷 권한 없음. 파일의 원본은 변경하지 않습니다.
- 제3자 웹사이트가 실제 파일 첨부 위치를 정렬하는 것을 앱이 강제할 수는 없으며, 번호 표시 또는 합친 이미지로 논리적 순서를 유지합니다.

## English

Image Order Studio beta 0.2.0 by **2bornot**. Supports Android 8+. Explicit tap-to-rank sequencing, reordering, selected-only/selected-first preview, visible numbered JPG/PNG exports, save-to-folder, combine-as-one, and order list clipboard. No network permission, trackers, ads or accounts. The recipient website may reorder attachment positions; visible labels preserve the intended logical order. Release APK is signed with a durable private release identity and verified for Android installation.
