# Image Order Studio v0.1.1 / 이미지 순서 스튜디오 v0.1.1

## 한국어
- 제작: 2bornot
- 갤러리에서 이미지 가져오기, 순서대로 선택, 개별 순번 표기
- 순번 이미지를 PNG로 내보내기, 공유, 지정 폴더에 저장
- 여러 장을 한 장으로 결합하는 기능 (크기 제한 있음)
- 인터넷 연결, 광고, 계정, 전체 사진 접근 권한 불필요
- 개발용 베타. 실기기 업로드/EXIF/대용량 테스트 필요

## English
- By 2bornot
- Import images, select explicitly in order, see numbered thumbnails
- Export numbered PNGs, save to a selected directory, share to other apps
- Optional single-file vertical composite (memory limits apply)
- No internet permission, ads, account, or broad gallery access
- Development beta; on-device attachment/EXIF/large-batch testing needed
