# 심안(心眼) v1.5.2 / Windows GUI Installer R3

## 수정 사항
- ChatLLM에서 목록 API가 수집기 시작 이후 도착해도 최대 16초까지 감지하여 목록 원문 조회 지속
- 목록 요청이 발생한 뒤에도 추출 항목이 없으면 반환 구조(필드 이름만)를 진단 로그에 기록
- 검색창에서 수집기가 최신 버전인데도 탭을 강제 새로고침하던 버전 비교 오류 수정
- Gemini·DeepSeek·Grok은 방문 기록 자동 저장이며 일괄 과거 기록 수집 대상이 아닌 것을 초기 화면에 명시
- Windows 설치관리자 Chrome/Edge 등록 버튼에서 브라우저 실행 후 주소창에 chrome://extensions/ 또는 edge://extensions/ 명시적 이동 지시
- Chrome에 포커스가 없으면 임의로 다른 프로그램에 키 입력을 보내지 않고 주소 복사 후 안내
- 프로그램 설치 파일은 스테이징 후 새 코드로 교체하며 문제 발생 시 이전 파일 복원

## 테스트
- Node: 지연된 ChatLLM 목록 HTTP 200 → 세션·원문 저장, 페이지네이션, Claude 수집 및 0건 진단, 저장소 왕복
- Chromium UI 모의 테스트: 전체 일괄수집 3서비스, 한글 검색, 진단 TXT 저장
- Windows GitHub Actions: 네이티브 GUI EXE 컴파일 및 설치/재설치 자동 테스트

정식 웹스토어 게시·실계정 전수수집 확인은 포함하지 않습니다.
