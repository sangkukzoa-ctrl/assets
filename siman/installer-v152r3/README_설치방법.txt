심안(心眼) v1.5.2 - Windows 간편 설치 R3
개발자: 2bornot

[신규 설치]
1) SimanSetup.exe 실행 → '설치 파일 준비하기'
2) Chrome 등록하기 → 확장프로그램 관리 화면 (chrome://extensions/)
3) 개발자 모드 켜기 → '압축해제된 확장프로그램을 로드'
4) 폴더 경로는 설치 관리자가 자동 복사합니다. 폴더 선택 창에서 Ctrl+V → Enter → 폴더 선택

[Chrome 홈 화면만 나올 경우]
브라우저 주소창에 chrome://extensions/ 입력 후 Enter. 설치 관리자에서 '폴더 주소 복사'를 누르고 폴더 선택 창에 붙여넣으세요.

[업데이트]
확장프로그램 삭제는 저장된 원문 색인을 지울 수 있습니다.
먼저 심안 '전체 원문 백업 저장'을 사용하세요.
설치 관리자는 프로그램 파일을 깨끗하게 새 버전으로 교체합니다. 이후 chrome://extensions/에서 심안을 새로고침해 주세요.
브라우저에서 아예 기존 확장을 삭제하는 경우 재등록 후 JSON 백업을 가져오세요.

[전체 일괄수집]
ChatLLM + Claude + ChatGPT가 순차 처리됩니다. 다른 사이트(Gemini·DeepSeek·Grok)는 현재 방문 대화 자동 저장 방식이므로 일괄 진행 대기 순서에 포함되지 않습니다.
실제 서비스에서 목록 조회 경로 및 수집 권한에 따라 결과가 다를 수 있습니다.

[진단]
검색 화면 '진단 로그 TXT 저장'으로 원문·로그인 정보 없는 오류를 저장합니다.

정식 웹스토어 등록 전에는 브라우저 최초 등록 승인 과정이 필요합니다.
이 GUI EXE는 Windows 코드서명 인증서로 서명되지 않았으며 SmartScreen 경고가 표시될 수 있습니다.
