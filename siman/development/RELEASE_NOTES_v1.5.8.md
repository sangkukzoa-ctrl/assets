# 심안(心眼) v1.5.8 Beta — Chrome·Edge 확장프로그램 자동 적용까지 통합

개발자: 2bornot

## 설치 및 업데이트

- 기존 `SimanSetup.exe` 실행 → 동일한 설치 폴더에 관리 대상 코드 파일 자동 덮어쓰기.
- Windows 설치 관리자가 Chrome·Edge의 사용자 프로필 `Preferences`를 **읽기 전용**으로 검사하여, 기존 심안의 설치 폴더와 정확히 일치하는 확장프로그램 ID를 찾습니다.
- 설치 관리자가 해당 브라우저 프로필의 심안 옵션 페이지를 자동으로 열어 업데이트 신호를 전달합니다.
- 기존 심안의 변경된 `search.js`는 브라우저에서 실행되어 `chrome.runtime.reload()`을 요청합니다.
- 새로운 Manifest V3 백그라운드 워커가 실행되면, 편집 중인 대화 입력은 보호하면서 열린 AI 사이트 탭의 새 코드를 반영하고 설치 관리자에 루프백(127.0.0.1) 확인 신호를 전송합니다.
- Windows 설치 관리자는 확장프로그램이 실제로 실행됐다는 확인 신호를 받은 경우에만 업데이트 완료로 판단하고 자동 종료합니다. 수동 재등록·기록 JSON 백업·확장 카드 새로고침을 요구하지 않습니다.
- Chrome 및 Edge 프로필 저장소와 `chrome.storage.local`의 대화 원문, 검색 색인, 기존 확장 ID를 삭제하거나 변경하지 않습니다.
- 사용자가 입력 중인 AI 메시지가 있는 탭은 자동 새로고침을 건너뛰어 입력 내용을 보존합니다. 해당 탭은 다음 탐색 시 새 코드를 적용할 수 있습니다.
- 브라우저 프로필을 찾지 못하거나 응답을 받지 못하면 설치 관리자에 완료라고 허위 표시하지 않고 상태 및 진단 로그를 남깁니다. 최초 설치는 브라우저 최초 등록이 한 번 필요합니다.
- 브라우저 전체 재시작, 원격 디버깅 포트 열기, Windows 관리자 권한, 기존 확장프로그램 제거가 필요하지 않습니다.

## 검증 범위

- 8개 Node 회귀 테스트: 과거 7개 테스트 + URL 기반 확장프로그램 재로딩, 일회용 로컬 완료 신호, 기존 데이터 및 AI 입력 보존 테스트.
- Windows 네이티브 EXE 빌드·신규 설치·업데이트·같은 폴더 유지·사용자 파일 보존·Chrome 프로필 설정에서 동일한 확장 ID 탐색 검사.
- Chrome for Testing 실 브라우저에서 v1.5.7 설치본 → v1.5.8 코드 덮어쓰기 → 새 확장프로그램 실행 → 설치 관리자 완료 신호를 검증하는 자동 통합 테스트를 추가했습니다. 통합 테스트가 통과한 경우에만 고정 Beta에 배포됩니다.
- Edge 사용자 실환경 및 브라우저 비표준 프로필은 계속 실사용 로그로 검증합니다.
