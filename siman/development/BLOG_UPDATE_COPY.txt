[심안(心眼) 최신 Beta — 자동 덮어쓰기 설치 안내]

심안은 공식 GitHub의 고정 다운로드 주소에서 최신 버전을 제공합니다.
개발자: 2bornot

■ 최신 버전: v1.5.9 Beta

기존 사용자는 SimanSetup.exe를 실행하기만 하면 동일한 설치 경로에서 기존 코드를 자동으로 덮어씁니다.
이전처럼 확장프로그램 삭제·재등록, JSON 원문 백업·복원, 설치 폴더 재선택을 반복하지 않아도 됩니다.
로컬 대화 원문·검색 색인은 Chrome/Edge 확장프로그램 ID의 브라우저 저장소에 그대로 남습니다.
기존 설치 폴더를 유지하며 사용자 파일을 보존하고, 오류가 발생하면 이전 버전으로 복원하도록 설계했습니다.

최초 설치에 한해서만 Chrome/Edge에 확장프로그램을 한 번 등록해야 합니다.
기존 Chrome/Edge 심안 확장프로그램 자동 재로드를 시도하며, 갱신 확인 ACK가 도착해야 완료로 표시합니다.
