# 심안(心眼) v1.5.5 Beta — 연결 복구·방문 대화 저장 안정화

이번 버전은 v1.5.4 기반의 수정판입니다. 기존 Chrome 확장프로그램 ID와 로컬 저장소 키를 유지하며, 저장된 대화 기록은 초기화하지 않습니다.

## 수정 사항

1. **Chrome 확장프로그램 오류 대응**: `content.js`가 저장소/기본 스크립트의 준비 상태를 확인하기 전에 예외를 발생시키던 코드를 변경했습니다. 초기 의존성이 늦게 준비되면 최대 20회 재확인하고, 완료 전에는 초기화 성공으로 표시하지 않습니다.
2. **방문 저장 누락 개선**: 실패한 저장을 성공으로 간주하지 않습니다. 저장 실패 시 같은 화면이라도 재시도하며, 계속 갱신되는 SPA 화면에서 4.5초 이내 저장을 시도하고 12초 주기 재검사를 추가했습니다. 텍스트 노드 변경 감지도 포함합니다.
3. **진단 기능 확대**: Gemini·DeepSeek·Grok의 현재 탭·대화 화면 여부, 메시지 요소 발견 여부, 저장 성공·오류 유형을 원문 없이 기록합니다 (`VISIT_CAPTURE`, `VISIT_SKIP`, `VISIT_ERROR`).
4. **연결 복구 확대**: 기존 ChatLLM·Claude·ChatGPT에 더해 Gemini·DeepSeek·Grok 탭도 「열린 탭 연결 재설정」으로 재연결할 수 있습니다.
5. **저장소 통신 초기화 검사**: 수집기 주입 직후 준비 완료 확인을 최대 8회 수행하고, 통신 실패 시 구체적인 복구 안내를 제공합니다.
6. **기존 기능 유지**: ChatLLM 응답 완결 판정과 ChatGPT 첫 HTTP 429 보호 중단(v1.5.4), Claude 전수 수집, DeepSeek 부분 누적 저장과 한국어 통합 검색을 유지합니다.

## 중요 사용 안내

- **업데이트 전:** 「전체 원문 백업 저장」을 통해 JSON 백업을 준비하세요. 수집 진행 중에는 중지 후 백업합니다.
- **업데이트:** v1.5.5 `SimanSetup.exe` 실행 → Chrome `chrome://extensions`에서 기존 심안 새로고침 → 열려 있던 AI 서비스 탭 새로고침. **확장프로그램을 삭제하지 않습니다.** 삭제하면 브라우저에 저장된 기록이 사라질 수 있습니다.
- **방문 저장:** Gemini·DeepSeek·Grok은 전체 과거 기록을 자동으로 수집하지 않습니다. 대화를 실제로 열고 화면에 나타난 메시지를 부분 저장합니다.
- **진단:** 결과가 0건이면 서비스 대화 탭을 연 상태에서 「진단 로그 TXT 저장」을 눌러 `방문 저장 서비스 진단`과 `VISIT_SKIP` 또는 `VISIT_ERROR`를 확인합니다. 텍스트는 로그인 정보와 대화 원문을 포함하지 않도록 설계했습니다.
- **서비스 측 HTTP 429:** 1차 보호는 v1.5.4에 반영됐습니다. 제한 해제 전 임의의 빈번한 재시도를 하지 않습니다.

## 검증 범위

- Node 테스트: ChatGPT 429 보호, ChatLLM 목록·완결 판정, Claude 수집, DeepSeek 가상 스크롤, 저장 브리지 왕복, 기존 기록 보존, 한국어 검색, 초기 의존성 지연, 저장 실패 재시도, 잦은 DOM 변경.
- Windows 설치 관리자: GitHub Actions의 Windows 러너에서 실행 파일 빌드, 설치 및 기존 파일 재설치, SHA-256 검증.
- **미검증:** 실제 로그인 계정에서 모든 서비스의 과거 기록 전수 수집. 이 실행 환경의 Chromium에서는 보안 정책으로 웹 도메인 접근이 차단되어 실제 브라우저 통합 시나리오가 완료되지 않았습니다.
- Windows Authenticode 서명 및 Chrome 웹스토어 게시 전입니다. 이번 릴리스는 공개 테스트판(Beta)입니다.
