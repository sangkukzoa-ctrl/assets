# 심안(心眼) v1.5.7 Beta — 자동 덮어쓰기 업데이트

개발자 2bornot

## 사용 경험 변경
- 기존에는 업데이트할 때마다 데이터 JSON 백업, 확장프로그램 삭제/재등록, 설치 폴더 선택이 필요한 것처럼 안내했습니다.
- 이제 Windows 설치 관리자 `SimanSetup.exe`를 **실행하는 즉시 자동 설치/업데이트**합니다. 수동 '설치 파일 준비하기' 단계도 없앴습니다.
- 이미 심안을 쓰고 있었다면 **기존 `%LOCALAPPDATA%\2bornot\Siman\app` 경로를 유지한 채 관리 대상 코드 파일만 덮어씁니다.**
- 기존 Chrome/Edge 확장프로그램 ID, 브라우저 프로필의 `chrome.storage.local` 대화 원문·검색 색인은 지우거나 수정하지 않습니다. 재등록·JSON 백업/복원 절차는 필요하지 않습니다.
- 코드 교체 전 설치 폴더에 롤백 복사본을 준비하고, 문제가 발생하면 기존 버전 복원을 시도합니다.
- 이전 설치기가 관리하던 코드 중 최신 버전에서 제거된 파일은 정리합니다. 사용자가 직접 넣은 관리되지 않는 파일은 보존합니다.
- 최초 설치 때만 한 번 브라우저에 확장프로그램을 등록하면 됩니다.
- **브라우저가 이미 실행 중이면 설치 후 기존 확장프로그램의 새로고침 또는 브라우저 재시작으로 새 코드를 반영해야 할 수 있습니다.** 확장프로그램 자동 재로딩까지 구현된 것은 아닙니다.

## 개발 검증
- CI에서는 설치 실행, 기존 버전 위에 덮어쓰기, 같은 설치 경로 유지, 관리 대상의 오래된 코드 제거, 사용자가 보관한 파일 유지, 롤백 구문 및 버전 정합성 검사, 7개 기존 Node 회귀 검사 및 Windows EXE 생성 검증을 수행합니다.

- 코드 서명 및 Chrome Web Store 정식 등록은 별도 과제입니다.
