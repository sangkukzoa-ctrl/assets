## 수정 내역

1. **Grok:** HTTP 401/403은 `GROK_AUTH` 진단을 남기고 '로그인 필요 · 대화 존재 여부 미확인'으로 완료 처리. HTTP 200 + 빈 정상 목록과 구분하고 로컬 기록과 카탈로그 보존. 로그인된 웹 요청의 `x-xai-request-id`를 사용 가능한 브라우저에서 부여. 인증이 사라진 경우 안전하게 재시도 상태 유지.
2. **Gemini:** 웹 `MaZiqc` 목록이 **최대 100건/페이지**라는 점을 반영. `[100, cursor, [0, null, 1]]` 형식으로 이어받고 응답 `payload[1]`의 다음 페이지 토큰을 따라 페이지네이션. 커서 반복/목록 미완료를 분리. 기존 100건이 전체 기록이라고 허위 표시하던 문제 제거.
3. **Gemini:** 일부 대화 `hNvQHb` 빈 프레임을 최대 2번 더 조회. 필요한 경우 웹 세션 정보를 다시 확인하고 권한/429를 구분. 응답 구조 오류, 빈 원문은 실패로 남겨 다음 실행에서 재시도.
4. **ChatGPT:** 429 종료 후 자동 이어받기는 기존 로컬 카탈로그를 참조해 **대화 전체 목록 API를 다시 요청하지 않음**. 완료된 대화는 건너뛰고 남은 원문만 조회. 수동 전체 수집은 기존처럼 새 대화 목록도 갱신. 서버 429를 우회하지 않고 보호 대기 유지.
5. **Chrome 확장:** 업데이트 후 구 실행 컨텍스트의 메시지 리스너·MutationObserver·주기 타이머를 종료하는 수명 관리 강화. 이미 주입된 확장은 중복 등록하지 않음. 기존 크롬 오류 카드의 과거 기록을 프로그램이 소급 삭제하지는 않으며, 최신 배포에서 **신규 오류 재발 여부**를 확인할 수 있도록 수집 진단 유지.
6. **배포:** Windows 설치 관리자 v1.5.12/R10, 동일 설치 경로·확장 ID·기존 저장소/원문·블로그 고정 다운로드 주소 유지.
