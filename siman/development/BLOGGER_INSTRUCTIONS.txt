네이버 블로그 심안(心眼) 고정 Beta 배포 지침

1. 블로그 글과 다운로드 링크는 새 버전마다 고치지 않습니다.
2. 게시글에는 아래 고정 링크를 한 번만 안내합니다.
   https://github.com/sangkukzoa-ctrl/assets/releases/tag/siman-beta
3. 사용자에게는 고정 링크에서 SimanSetup.exe 또는 Siman-Windows.zip을 받으라고 안내합니다.
4. SimanSetup.exe를 실행하면 기존 설치된 심안은 같은 폴더에 자동으로 덮어써집니다.
5. 기존 확장프로그램 삭제/재등록 및 JSON 백업/복원은 일반 업데이트에서 필요하지 않습니다.
6. 실행 중인 Chrome/Edge에서 새 코드가 반영되지 않으면 기존 심안 확장프로그램만 새로고침하거나 브라우저를 재시작하도록 안내합니다.
7. 새 버전 출시 때마다 GitHub Actions가 Windows EXE 빌드·업데이트 회귀 테스트·고정 릴리스 배포·익명 다운로드 검증을 진행합니다.

기존 버전 릴리스는 이력 보존용이며 블로그에서는 고정 Beta를 안내합니다.
