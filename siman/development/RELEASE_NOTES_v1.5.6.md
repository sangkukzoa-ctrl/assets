# 심안(心眼) / Siman v1.5.6 Beta — ChatLLM 수집 중단 대응

2026-11-10 사용자 v1.5.5 실사용 로그를 중심으로 수정했습니다.

## 확인된 실사용 상태

- ChatLLM: 301개 발견, 41개 완료/260개 미수집. 첫 상세 조회가 HTTP 200에 도달한 뒤 진행 신호가 끊어지고 95초 연결 타임아웃 발생.
- ChatGPT: 643개 발견, 198개 완료, 444개 미수집 및 1개 재시도 대기. 첫 HTTP 429에서 제한을 준수하고 중단하는 기존 기능은 정상 동작.
- Claude: 103개 발견 및 103개 완료.
- Gemini·DeepSeek·Grok: 열린 탭 없음, 방문 수집 0개. 이 로그만으로 방문 저장 코드 고장이라고 결론내리지 않음.

## 수정사항

1. **ChatLLM 상세 JSON 본문 타임아웃 누락 수정**: HTTP 헤더를 받은 후 응답 본문을 읽는 동안에도 AbortController 타이머가 유지되도록 네트워크 replay를 수정.
2. **직접 API 요청 본문 타임아웃 수정**: HTTP 200 이후 `response.json()` 응답 대기 역시 제한 시간 안에 종료. 실패 시 기존 로그에 민감한 메시지 원문 없이 네트워크 오류 기록.
3. **ChatLLM 단계별 진행률 진단**: 관찰된 상세 요청, 직접 조회, HTML 내보내기, 기존 완료 건 스킵을 구별.
4. **일괄수집 자동 연결 복구**: 서비스 탭 수집기가 중단된 경우 저장된 완료 원문을 지우지 않고 최대 1회 재연결 및 재개.
5. **회귀 테스트 강화**: HTTP 200 뒤 JSON 본문이 끝나지 않는 ChatLLM 응답을 실제로 모의하여 60초 AbortController가 여전히 활성 상태인지 확인. 429 보호 동작과 저장된 데이터 보존 테스트도 유지.
