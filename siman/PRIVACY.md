# 심안 (心眼) 개인정보 처리 안내

개발자: 2bornot. 심안은 사용자의 로그인된 AI 서비스에서 확인 가능한 대화 제목, 메시지 원문, 세션 ID, 프로젝트명 및 원본 URL을 브라우저 로컬 저장소(chrome.storage.local)에 색인합니다.

- 원문 검색은 사용자의 컴퓨터에서 이루어집니다.
- 자체 수집 서버나 별도 AI 모델 호출은 없습니다.
- 각 서비스의 데이터를 동기화할 때 해당 서비스에 원문 조회 요청을 전송할 수 있습니다.
- 사용자가 선택하면 JSON 백업 파일을 로컬 컴퓨터에 저장할 수 있습니다.
- 확장프로그램의 '로컬 색인 초기화'로 저장 기록을 삭제할 수 있습니다.
- 로그인 정보나 API 키는 프로그램의 백업에 저장하도록 설계되어 있지 않습니다.

문의: 개발자의 공식 배포 블로그(2bornot_)를 이용해 주세요.
