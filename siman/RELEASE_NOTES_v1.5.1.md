# 심안(心眼) v1.5.1 — 수집기 저장소 통신 진단 보강 (Preview)

## 해결한 문제
- v1.5.0이 수집 스크립트의 존재만 확인하고 로컬 저장소와 실제 통신했는지 확인하지 않았던 오류 수정
- 수집 시작 전 MAIN 페이지 ↔ ISOLATED 확장 저장소 **읽기·쓰기 왕복 확인** 추가
- 페이지 스크립트와 수집 스크립트 버전 채널을 분리하고 새 초기화 여부 확인
- ChatLLM 발견 목록 건수를 먼저 기록하며 긴 조회 중 진행 신호 추가
- 상세 진단 TXT에 저장소 왕복 성공/실패와 마지막 수집 단계 포함
- 기존 v1.5.0 로컬 색인 보존

## 검증
- Node VM 독립 실행 컨텍스트 간 postMessage → chrome.storage → ChatLLM 원문 저장 테스트
- ChatLLM·Claude 수집기 회귀 테스트
- Chromium UI 모의 실행: 일괄수집 3개 서비스, 한국어 '마군' 검색 3건, TXT 진단 저장
- Windows CMD 신규 설치·기존 설치 업데이트 GitHub Actions

실제 로그인한 ChatLLM·Claude·ChatGPT 계정의 모든 세션을 직접 조회한 검증은 아닙니다. **프리뷰 버전**입니다. API 키나 AI 모델 토큰은 필요하지 않습니다. 정식 웹스토어 인증 게시 전입니다.
