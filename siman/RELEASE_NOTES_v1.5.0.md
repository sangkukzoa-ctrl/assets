# 심안(心眼) v1.5.0 — 일괄수집 + 상세 진단 (Preview)

- 「전체 일괄수집 시작」 한 번으로 ChatLLM → Claude → ChatGPT 순차 실행합니다. 완료된 세션은 재조회하지 않습니다.
- 기존의 서비스별 수집·연결 복구·백업을 접을 수 있는 고급 메뉴로 이동했습니다.
- 「진단 로그 TXT 저장」 추가: 요청 경로(쿼리 제외), HTTP 코드, 수집기 준비 상태, 수집 완료·실패 통계 및 단계별 로그를 저장합니다.
- 검색 원문이나 인증 정보를 디버그 TXT에 넣지 않도록 마스킹합니다.
- Extension context invalidated 등 업데이트 후 남아 있는 오래된 탭 스크립트는 버전 검사 후 해당 탭을 재연결하도록 수정했습니다.
- 동기화 시 요청 60초 타임아웃, 중단 시 활성 HTTP 요청 취소, 끊긴 실행을 감지하는 일괄수집 watchdog 추가.

## 검증

- ChatLLM·Claude 모의 목록/상세 수집 회귀 테스트 5개 통과.
- Chromium UI 모의 환경에서 전체 수집 3개 완료, `마군` 검색 3건, 디버그 TXT 생성 및 테스트 대화 원문 제외 검사 통과.
- 실제 로그인된 서비스와의 통합 수집은 계정 접근이 없는 환경에서 검증하지 않았습니다.
- GitHub Actions에서 Windows 신규 설치·기존 버전 업데이트·ZIP 해시 검증을 수행합니다.
