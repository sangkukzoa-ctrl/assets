심안(心眼) Windows 간편 설치 관리자 R2
확장프로그램 버전: 1.5.1
개발자: 2bornot

[최초 설치]
1. SimanSetup.exe를 실행합니다. 관리자 권한은 필요 없습니다.
2. '설치 파일 준비하기' 클릭.
3. 'Chrome 등록하기' 또는 'Edge 등록하기' 클릭.
4. 브라우저 확장프로그램 화면에서 개발자 모드를 켭니다.
5. '압축해제된 확장 프로그램을 로드'를 클릭합니다.
6. 폴더 선택 창에서 주소창에 Ctrl+V, Enter를 누르고 '폴더 선택'을 누릅니다.
   ※ 설치 폴더 주소는 설치 관리자가 자동으로 복사합니다. 드래그 앤 드롭 불필요.
7. 확장프로그램 목록에 심안(心眼)이 나타나면 완료입니다.

[기존 심안에서 재설치]
1. 기존 심안이 열리면 '전체 원문 백업 저장'을 먼저 실행해 JSON을 안전한 곳에 보관합니다.
   ※ 브라우저에서 확장프로그램을 제거하면 저장된 색인이 삭제될 수 있습니다.
2. 브라우저 확장프로그램 화면에서 이전 심안을 '제거'합니다.
3. SimanSetup.exe 실행 → '설치 파일 준비하기' → 브라우저 등록.
4. 새 심안 화면의 'ZIP / JSON 기록 가져오기'로 백업 JSON을 복원합니다.

[설치 방식]
* 설치되는 코드 파일: %LOCALAPPDATA%\2bornot\Siman\app
* 이전 버전 코드 폴더를 추적하거나 여러 경로에 덮어쓰지 않습니다.
* 표준 폴더를 임시 폴더로 교체한 뒤 신규 파일로 설치하며 실패하면 이전 파일로 복구합니다.
* Chrome/Edge 사용자 프로필 및 브라우저 저장 데이터는 설치 관리자가 직접 수정하지 않습니다.
* 설치 로그: %LOCALAPPDATA%\2bornot\Siman\setup.log
* 공식 웹스토어가 아닌 테스트판이므로 브라우저에서 확장프로그램 최초 등록을 승인해야 합니다.
* Windows에서 서명되지 않은 자체 배포 EXE에는 SmartScreen 경고가 표시될 수 있습니다.

[정식 원클릭 설치]
Chrome Web Store, Edge Add-ons에 게시 및 승인된 뒤에는 웹스토어 링크로 최초 설치/자동 업데이트가 가능합니다.
이 설치 관리자는 스토어 출시 전 사용자를 위한 개선된 설치 도구입니다.
