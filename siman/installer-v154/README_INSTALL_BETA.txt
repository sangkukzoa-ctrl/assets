심안(心眼) v1.5.4 Beta — Windows Chrome/Edge

1. 압축 해제 후 SimanSetup.exe를 실행합니다.
2. 설치/업데이트 버튼을 클릭해 프로그램 파일을 준비합니다. 관리자 권한은 필요 없습니다.
3. 처음 설치하는 경우 설치 관리자의 브라우저 등록 안내에 따라 확장프로그램 관리 화면에서 개발자 모드를 켜고 '압축해제된 확장 프로그램을 로드'로 app 폴더를 등록합니다.
4. 기존 설치본을 갱신하는 경우 확장프로그램 자체는 삭제하지 말고 chrome://extensions 에서 심안 새로고침(↻)을 누릅니다. 열려 있던 ChatGPT·Claude·ChatLLM·DeepSeek 탭도 새로고침합니다.
5. 심안에서 전체 일괄수집을 실행합니다. ChatGPT가 HTTP 429로 중단됐을 때는 표시된 재시도 시각 이후 다시 수집하면 됩니다.

중요: 현재 수집이 진행 중이면 완료되거나 중지한 후 업데이트하세요. 업데이트 전에 '심안 전체 백업 저장'으로 JSON을 저장해 두길 권장합니다.
Chrome 웹스토어 등록이 완료된 확장프로그램이 아니므로 최초 설치에는 개발자 모드가 필요합니다. 실행파일은 Windows 코드서명 인증서를 사용하지 않아 경고가 표시될 수 있습니다.
