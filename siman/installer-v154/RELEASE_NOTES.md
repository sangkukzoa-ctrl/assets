# 심안(心眼) v1.5.4 Beta — 중간 진단 반영

## 확인된 실제 진단 (v1.5.3)

- ChatLLM: 발견 301건 / 원문 저장 성공 301건. 상태상 완결 96건, 완결 미확인 205건.
- Claude: 91건 전부 저장 완료.
- ChatGPT: 624건 발견, 21건 완료 상태에서 429가 연속 발생.
- Gemini · DeepSeek · Grok: 일괄수집 대상이 아니라 **방문 화면 자동 저장** 대상. 발견 0건이 일괄수집 대기 상태를 뜻하지는 않습니다.

## v1.5.4 수정

1. **ChatLLM 원문 판정 수정** — `totalEvents`는 내부 이벤트를 포함할 수 있어, 이를 검색 가능한 메시지 건수와 곧바로 비교하지 않습니다. 상세 응답에 후속 페이지(`hasMore`, `nextCursor`) 표시가 있으면 부분 수집으로 유지하며, 후속 페이지 표시 없는 상세 응답은 제공된 메시지 기준으로 완료 처리합니다. 기존 v1.5.3 일부 수집 기록은 다음 재수집 때 판정이 갱신됩니다.
2. **ChatGPT 429 반복 호출 중단** — 최초 HTTP 429 응답에 즉시 수집을 보류하고, 서버 `Retry-After` 및 최소 15분 보호 대기 중 더 이상의 상세 요청을 하지 않습니다. 완료 기록을 지우지 않으며, 재개 시각이 지난 후 사용자가 수집을 다시 실행할 수 있습니다.
3. **수집 현황 표시 개선** — '원문 저장 성공', '원문 완결', '일부 확보/완결 미확인', '계정 목록 확인 여부'를 구분합니다.
4. 기존 Claude·DeepSeek 정상 작동 경로 및 v1.5.3 사용자 색인 저장소 키를 그대로 유지합니다.

## 지원 범위

- ChatLLM / ChatGPT / Claude: 순차 전체 일괄수집 시도, 기존 완료 세션 건너뛰기.
- DeepSeek / Gemini / Grok: 브라우저에서 **방문한 화면에 나타난** 대화 일부 자동 저장 (전체 과거 일괄수집 아님).
- ChatGPT에서 HTTP 429가 자주 발생하면 서비스의 공식 데이터 내보내기 ZIP/JSON 가져오기를 사용할 수 있습니다.
