[2026.11.08 업데이트] 심안(心眼) v1.5.4 Beta 배포

기존 공개 테스트판 v1.5.3에서 확인된 수집 진단을 반영해 v1.5.4로 업데이트했습니다.

[주요 변경사항]
1. ChatLLM 원문 완결 판정 수정: 내부 이벤트(totalEvents) 수가 실제 대화 메시지 수보다 많을 때, 정상적으로 저장된 원문이 불필요하게 '부분 수집'으로 분류되던 문제를 보완했습니다. 다만 추가 페이지가 확인되는 대화는 계속 부분 수집으로 표시합니다.
2. ChatGPT HTTP 429 대응: 한 번 요청 제한을 받으면 같은 요청을 반복하지 않고 수집을 중단합니다. 서버의 재시도 지시 또는 최소 15분 경과 후 '수집·재개'를 누르면 미완료 세션부터 이어갈 수 있습니다.
3. 수집 상태 문구 개선: '원문 저장'과 '전체 세션 목록 수집 완료'를 구분하고, 완결 미확인 기록을 명확히 표시합니다.
4. 기존 Claude·DeepSeek 등의 기능과 로컬 검색 색인을 유지합니다.

[설치·업데이트]
첨부한 새 Siman_v1.5.4_BLOG_ATTACHMENT.zip 파일을 압축 해제하고 SimanSetup.exe를 실행합니다.
기존 심안을 사용 중이라면 삭제하지 말고, 먼저 프로그램 안의 '심안 전체 백업 저장'으로 기록을 JSON 파일로 저장해 두시길 권장합니다. 설치 관리자는 이전 프로그램 파일을 새 코드로 교체합니다.
설치 후 Chrome 주소창에 chrome://extensions 를 입력하고, 심안의 새로고침 버튼(↻)을 누릅니다. 열려 있던 AI 서비스 탭도 새로고침합니다.

[주의 및 개발 현황]
이번 버전도 공개 테스트판(Beta)입니다. ChatLLM·ChatGPT·Claude의 일괄수집은 각 서비스의 조회 제한 및 웹페이지 응답 구조에 영향을 받습니다. DeepSeek·Gemini·Grok은 전체 일괄수집이 아니라 방문한 대화 자동 저장 방식입니다.
문제가 발견되면 '진단 로그 TXT 저장'을 이용해 제보해 주세요. 원문과 로그인 정보는 포함하지 않도록 설계되어 있습니다.

기존 v1.5.3 블로그 글에 첨부한 설치 ZIP과 다운로드 주소를 v1.5.4로 교체하고, 이 업데이트 공지를 글 상단에 추가했습니다.
