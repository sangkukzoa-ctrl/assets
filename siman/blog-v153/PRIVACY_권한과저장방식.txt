심안(心眼) v1.5.3 개인정보·권한 안내

이 확장프로그램은 웹의 AI 대화를 통합 검색하기 위해 해당 AI 서비스의 대화 내용, 세션 제목과 ID, 원본 링크, 프로젝트명 등을 브라우저 로컬 저장소에 보관합니다.

권한: 저장소(storage), 탭(tabs), 스크립트(scripting), 저장 용량(unlimitedStorage). 사이트 접근 대상: ChatGPT, Claude, ChatLLM(Abacus), Gemini, DeepSeek, Grok. 서비스별 원문 수집 시 해당 서비스의 서버에 요청을 보내며 별도 AI 모델 생성 요청은 하지 않습니다.

심안이 만든 로컬 검색 색인은 사용자 브라우저에서 처리되며, 개발자 서버로 대화 원문을 자동 전송하는 별도 동기화 서버는 포함되지 않은 설계입니다. 사용자가 JSON 백업을 내보내면 그 파일은 사용자가 선택한 저장 위치에 생성됩니다.

확장프로그램을 제거하면 로컬 기록이 삭제될 수 있으므로 중요한 기록은 별도로 JSON 백업하세요. 상세 오류 로그는 대화 원문 및 로그인 정보를 포함하지 않도록 구현되어 있으나, 파일을 공유하기 전에 내용 확인을 권장합니다.
