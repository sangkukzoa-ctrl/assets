[무료 배포 / 공개 테스트판] 심안(心眼) v1.5.3 — AI 대화 통합 검색 프로그램

ChatGPT나 Claude 등 여러 AI 서비스를 이용하다 보면 이전에 나누었던 대화를 다시 찾아야 할 때가 많습니다.

특히 세션이 수백 개씩 쌓이고 프로젝트별로 대화가 나뉘어 있으면, 어떤 세션에서 무슨 이야기를 했는지 기억하는 것부터 일이 됩니다. 화면에 보이는 글자를 찾는 Ctrl+F가 아니라, 여러 세션에 저장된 대화 원문 전체에서 키워드를 검색하고 싶었습니다.

예를 들어 검색창에 '마군'을 입력하면, 그 단어가 나왔던 대화와 메시지 내용을 확인하고 필요한 부분을 복사할 수 있는 방식입니다.

그래서 직접 만든 프로그램이 심안(心眼)입니다. 개인적으로 사용하려고 개발했지만 비슷한 불편을 겪는 분들도 있을 것 같아 무료로 배포합니다.

■ 주요 기능

- AI 서비스별 대화 기록을 하나의 로컬 색인에서 검색
- 세션 제목이 아닌 사용자·AI 메시지 원문 키워드 검색
- 검색 결과의 전후 문맥 확인 및 원문 복사
- 가능한 경우 원본 대화로 이동
- 전체 일괄수집 버튼과 서비스별 수집 진행 상태
- JSON 백업·복원, 오류 진단 TXT 저장
- 별도 AI 모델 호출이나 API 키 없이 로컬에서 검색

■ 지원 서비스와 현재 범위

ChatGPT / Claude: 저장된 과거 대화를 일괄수집하는 기능을 제공합니다. 서비스 측 요청 제한이나 로그인 상태에 따라 일부 기록은 나중에 다시 수집해야 할 수 있습니다.

ChatLLM (Abacus AI): 전체 수집을 지원하도록 개발 중입니다. 현재 일부 환경에서 대화 목록 인식이 실패하는 문제가 남아 있어 지속 수정하고 있습니다.

DeepSeek / Gemini / Grok: 과거 기록의 전체 일괄수집이 아니라, 웹에서 방문하여 화면에 표시한 대화를 자동으로 저장하는 방식입니다. 긴 대화는 스크롤에 따라 일부만 저장될 수 있습니다.

■ v1.5.3 변경사항

- DeepSeek 웹의 실제 세션 주소 인식 수정
- DeepSeek 사용자·AI 메시지와 가상 스크롤 영역의 누적 저장 보강
- 원본 DeepSeek 대화 링크 보존
- ChatLLM 지연 목록 감지 및 설치 관리자 개선(v1.5.2 내용 포함)

■ 다운로드 및 설치

[첨부] Siman_v1.5.3_BLOG_ATTACHMENT.zip

GitHub 공식 배포: https://github.com/sangkukzoa-ctrl/assets/releases/tag/siman-v1.5.3

1. 첨부 ZIP을 압축 해제합니다.
2. SimanSetup.exe를 실행하고 '설치 파일 준비하기'를 누릅니다.
3. 'Chrome 등록하기'(Edge 사용자는 'Edge 등록하기')를 누릅니다.
4. 브라우저의 확장프로그램 관리 화면에서 '개발자 모드'를 켭니다.
5. '압축해제된 확장 프로그램을 로드'를 눌러 설치 관리자가 복사해 둔 폴더 주소를 붙여넣고 폴더를 선택합니다.

브라우저가 확장프로그램 관리 화면 대신 시작 화면을 연 경우, 주소창에 chrome://extensions (Edge는 edge://extensions)를 입력하면 됩니다.

설치가 끝나면 확장프로그램 목록에서 심안을 실행하고, '전체 일괄수집 시작' 버튼을 눌러 ChatLLM·Claude·ChatGPT 수집을 시작합니다. 수집된 내용은 검색창에 원하는 키워드만 입력하면 확인할 수 있습니다.

DeepSeek·Gemini·Grok은 해당 사이트에서 대화를 열어 방문 저장 기능을 이용합니다.

■ 업데이트 및 백업

심안은 브라우저 로컬 저장소에 검색 데이터를 보관합니다. 확장프로그램을 삭제하면 저장된 색인이 사라질 수 있으므로, 업데이트 전 '심안 전체 백업 저장'으로 JSON 파일을 보관하는 것을 권장합니다.

기존 확장프로그램을 유지한 채 새 설치 관리자로 프로그램 파일을 교체한 경우에는 chrome://extensions에서 심안을 새로고침하고 열려 있던 AI 탭도 새로고침해 주세요. 새로 설치해야 하는 경우에는 기존 JSON 백업을 가져오면 됩니다.

■ 테스트판 안내

이번 v1.5.3은 정식 완성판이 아닌 공개 테스트판(Beta)입니다. ChatLLM 수집, 일부 서비스의 원본 메시지 위치 이동, 오래된 세션의 수집 누락 등은 계속 개선할 예정입니다. 검색 결과가 보이지 않으면 실제 원문이 '수집 완료' 상태인지 먼저 확인해 주세요.

오류가 발생하면 심안의 '진단 로그 TXT 저장' 기능으로 로그를 내보낼 수 있습니다. 로그인 정보와 대화 원문은 로그에서 제외하도록 설계했습니다. 문제 제보 시 로그를 첨부하면 원인을 분석하는 데 도움이 됩니다.

현재 Chrome 웹스토어 정식 등록 및 Windows 코드 서명은 완료되지 않았습니다. 따라서 설치 과정에서 브라우저 개발자 모드가 필요하며, Windows 보안 경고가 표시될 수 있습니다. GitHub 릴리스에는 SHA-256 검증값도 제공합니다.

차기 버전에서도 설치와 데이터 이전, 수집 안정성을 계속 개선하겠습니다.
