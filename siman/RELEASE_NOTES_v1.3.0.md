# 심안 v1.3.0 변경사항

- ChatGPT HTTP 429 자동 대기 및 재시도 기능 유지.
- Claude/ChatLLM에도 요청 속도 제한과 429 대기·정지·재개 상태 적용.
- 검색 가능/발견/완료/부분/미수집/재시도/실패 상태 표기 강화.
- 원문 미포함 수집 상태 진단 복사 버튼 추가.
- Windows 기존 설치 경로 자동 탐지 업데이트 도우미 추가.
- 불필요한 downloads 권한 제거.

모의 서버 및 오프라인 Chromium UI 테스트는 통과했습니다. 실계정 전수 수집과 Windows PowerShell 동작 검증은 수행하지 못했습니다.
