# Copy/paste starting prompt for DeepSeek Flash 4.1 in ordinary Chat LLM

아래의 저장소는 Android 앱 Just PDF to Image (개발자 2bornot)의 실제 인수인계 환경이다.

https://github.com/sangkukzoa-ctrl/assets/tree/pdfimage-handoff/2026-11-26

원본 앱 소스는 project/ 디렉터리, 인수인계 문서는 HANDOFF/ 디렉터리에 있다.
HANDOFF/00_START_HERE.md -> STATE.json -> TASKS.md -> 01~05 문서를 먼저 읽고, 실제 Java/Gradle 파일을 직접 열어 원본 소스를 확인하라.
GitHub 정식 공개 v1.3.1: https://github.com/sangkukzoa-ctrl/assets/releases/tag/v1.3.1
전체 소스 ZIP: https://github.com/sangkukzoa-ctrl/assets/releases/download/v1.3.1/JustPDFtoImage-v1.3.1-Source.zip

너는 ABACUS.AI 일반 CHAT LLM의 DeepSeek Flash 4.1에서 작업한다. **에이전트를 사용하지 마라.** GitHub 연동에서 실제로 허용되는 읽기/쓰기/Actions 기능만 사용하고, 실행하지 않은 작업은 실행했다고 보고하지 마라.

프로젝트 철학: PDF -> PNG/JPG 변환 하나에 집중하는 무료·무광고·무회원가입·무인터넷·무제한 Android 유틸리티. PDF 다중 일괄 변환, SAF 파일 저장, 원본 JPEG 무손실 추출 별도 모드, 한국어/영어 지원. 개발자 이름 2bornot, 앱명 Just PDF to Image. 기존 package/applicationId com.hsiwan.pdfimage와 정식 서명 인증서의 업데이트 호환성을 보존하라. 원본 서명 개인키와 비밀번호를 공개 저장소에 올리지 마라.

**이번 대화에서 새 개발 지시를 하는 것이 아니다.** 지금은 인수인계 서류와 실제 프로젝트 파일을 검토하여 현재 출시/빌드/환경을 정확히 이해하고, 연결 권한 및 재개 가능 상태를 짧지만 구체적으로 보고하라. 새 기능 구현, 파일 수정, 커밋, Actions 실행, 릴리스 발행은 시작하지 마라. 이후 내가 개발 과제를 지시하거나 승인된 작업 중 "진행"이라고 하면 STATE.json/TASKS.md와 당시 로그를 기준으로 바로 작업을 이어가라. 이미 제공된 요구사항을 반복 질문하지 마라.
