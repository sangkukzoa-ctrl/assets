## 검증 결과/한계
Go 1.23.2 Linux amd64에서 정확한 빌드 플래그로 바이너리 완전 일치. 원본 Windows GUI PE. 기본 vet unsafe.Pointer 9건, 해당 검사 제외 vet 통과, 단위 테스트 없음. Windows/FF14/카카오톡 실행 결과 및 v1.7.13 사용자 체감 미확인.

## 실사용 테스트(향후 지시 또는 사용자 보고 시)
- 단축키 즉시 타이핑, 빠른 Esc/토글, Enter 후 실제 발신·게임 포커스·카톡 창 상태, 한글 IME와 Enter 조합, 빠른 연속 전송, 최소화/비최소화 대상, 다른 방 전환 중 확인 결과, 수신 알림/최근 대화/클립보드 유지.
- v1.7.13 로그: `reply sent to Kakao ... game foreground restored in ...` 및 `background send verification finished ...`는 구간 지표이며 SetForegroundWindow 성공을 검증한 값은 아님. 실제 게임 포커스 및 전송 결과와 교차 확인.
- 전송 확인 실패가 실제 발신 실패와 동의어가 아니다. 빠른 복귀를 유지한 채 검증 성공률을 시험할 것. 복사 작업을 전면 포커스 경로로 되돌리는 것은 승인 없이 금지.
- 최소화되지 않았던 카카오톡은 강제 최소화하지 않고 게임 창으로 포커스를 돌리는 구조. 사용자의 불만이 남을 경우 실제 상태를 구분한다. 새로운 이슈를 추정으로 단정하지 않는다.
