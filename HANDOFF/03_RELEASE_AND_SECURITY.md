# 배포/보안
- 개발자 2bornot. 네이버 블로그 무료 공개 ZIP, 무설치 Windows x64. 공개 배포에 코드 서명은 필수 아님. 서명 없이 SmartScreen/UAC 경고가 나타날 수 있다. 공인 인증서 발급/유료 구매는 현재 지시 아님. 자체 서명으로 Windows 신뢰를 해결했다고 주장하지 말 것.
- v1.7.12 공개 준비본에서 개인용 `여자친구 카톡방` 안내를 `대상 카톡방`으로 변경; 기능 유지. v1.7.13은 이 공개판 기반. 배포용/개인용 기능 분리 불필요. 파일명은 FF14KakaoBridge_v버전.zip. 원본 SHA256.txt는 EXE 해시.
- 최신 제작 버전과 실제 블로그 게시 버전을 구분. v1.7.13 사용자 실기기 결과 미확인. 다운로드 ZIP, 원본 Go 소스, 설명서, 변경내역, 체크섬을 함께 유지하는 기존 방식.
- UAC 관리자 권한은 기존 프로그램 요구사항. 배포 때 이유와 프로그램 역할을 명시. Windows 보안 전체 해제 안내 금지.
- 실제 config/history/app.log에는 채팅방 이름/메시지 등의 개인정보가 포함될 수 있다. 이관 ZIP과 GitHub에는 실제 사용자 설정, 대화, 로그, 토큰, 인증서 개인키를 넣지 않는다. 필요한 진단은 민감값 제거한 로그만 사용.
- 공유 저장소는 public. 소스와 인계 문서만 독립 브랜치에 올리고 unrelated 파일이나 메인 브랜치 수정 금지. baseline 배포 ZIP은 이관 첨부에만 보존해 원격 중복 업로드하지 않는다. 새 GitHub Release, 태그, 네이버 포스팅 수정은 사용자 지시 후에만.
