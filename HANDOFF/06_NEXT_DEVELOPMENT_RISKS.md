# 재개 우선순위 — 참고 과제 (새 작업 승인 아님)

**P0 데이터/설치 연속성**: v1.5.13 사용자 Chrome 실제 설치 ACK와 setup.log 확인. GPT 532→183 완료 감소를 먼저 진단. 기존 확장 ID/프로필별 archive count, catalog 상태, 실제 원문 개수 대조. 기존 원문을 삭제하거나 새로 등록해서 '해결' 금지. 브라우저 오류의 정확한 exception/stack과 새/과거 발생 시점 구별. 사용자 입장에서 EXE 1회 실행만으로 코드 적용이 확인되어야 한다.

**P1 수집 완결성**: GPT 429/재개 잔여, Claude 503 복구, ChatLLM 새로운 대화 및 프로젝트/일반 계정 목록 증분 탐색, Gemini/DeepSeek 반복 수집 및 최신 대화 갱신, Grok 정상 로그인과 빈 계정 실검증. 전체 계정 목록과 발견 범위 완결 분리. 실제 사용자 로그로 검증. 무제한 retry 또는 429 우회 금지.

**P2 UX 원본 위치**: 모든 원문 전문 검색, 전후 맥락, 복사, 서비스별 원본 링크, 가능한 해당 메시지 위치 이동 개선. 검색 품질을 희생하는 단순 UI 수정 금지.

**P3 수집 실행 수명**: 기존엔 AI 탭 내에서 실행되어 탭 닫으면 중단, 심안 검색창 닫으면 다음 bulk 단계/자동 resume 종료. 사용자 탭과 수집 전용 탭 분리 및 안전한 중지·재개 구조는 제안 상태. 별도 승인 후 설계/실제 Chrome 시험.

**P4 설치 유통**: 실제 Edge/Dev Mode OFF/비표준 프로필 검증, Chrome Web Store/Edge Add-ons 등록 및 Windows Authenticode 서명은 미완료. 등록/서명 비용과 보안 정책을 존중. 자동 업데이트 설계를 고정 URL 방식과 혼동 금지.

우선순위는 다음 업무 지정 시 자료로 사용한다. 현재 승인된 새 구현 과제 없음. 실계정 정보가 없으면 모의/CI/실사용 구분을 명시하고 원인을 증명하기 위한 코드·테스트 범위에서만 진행.
