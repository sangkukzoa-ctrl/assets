# 주요 결정과 변경 금지 범위
- 이관의 기준은 v1.7.13 실제 소스/바이너리. v1.7.12는 비교/롤백용. 오래된 v1.7.8이나 v1.8.0 후보를 버전 번호만으로 선택하지 않는다.
- UAC, 지정방, 기본 단축키, 오버레이, 수신/알림/설정 호환을 그대로 유지한다.
- 단축키 열기 시 카카오톡 대화 복사 완료를 기다리지 않는다; 첫 키 로그 I/O 제거 유지.
- 전송 확인은 게임 복귀 후 백그라운드 EVA-only. false-negative 가능성은 검증 항목이지 확정된 새 결함 아님.
- 기존 카카오톡 메시지 처리/알림 억제에 대해 성급하게 구조를 바꾸지 않는다. 실제 증상과 로그를 기반으로 수정.
- 무료 미서명 배포, 네이버 블로그 사용자가 직접 배포. 공인 코드 서명 구매는 필수 아님.
- GitHub `assets` 공유: 인계 브랜치만 구성, main 변경·병합·릴리스 금지. PAT/대화 로그/사용자 config는 패키지에 없음.
- 이번 인계는 기존 PDF 방식에 맞췄으나 원본은 대화 첨부에 있어 원격 등록 전 로컬 완전 패키지 우선. 등록 스크립트는 준비만 했고 실행 안 함. 최초 사용자 메시지의 환경 구성 승인에 따라 Chat LLM에서 등록한다.
