# Privacy policy / 개인정보처리방침

## 한국어
PDF Image는 이용자 개인정보, PDF 내용, 변환 이미지를 수집하거나 전송하지 않습니다. 광고, 이용 통계, 분석 SDK, 계정 서비스, 인터넷 접속 권한을 사용하지 않습니다. 선택한 문서는 안드로이드 시스템 파일 선택기로만 접근하고, 결과는 이용자가 지정한 로컬 폴더에 저장됩니다.

## English
PDF Image does not collect or transmit personal information, PDF contents or exported images. It has no advertisements, analytics SDKs, accounts or internet permission. Files are accessed through the Android system file picker and output images are saved in the folder chosen by the user.
