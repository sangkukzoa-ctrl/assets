개인정보 수집

본 앱은 계정 등록을 요구하지 않으며, 개인정보, 사용 통계, 광고 식별자 또는 기기 식별자를 수집하지 않습니다.

파일 처리

앱이 접근하는 PDF는 사용자가 Android 파일 선택기를 통해 선택한 파일에 한정됩니다. PDF 변환은 오프라인으로 기기 내부에서 수행되며 문서 내용 및 변환 결과를 개발자 또는 제3자 서버에 업로드하지 않습니다. 변환된 이미지는 사용자가 지정한 폴더에 저장됩니다.

권한 및 외부 서비스

본 앱은 인터넷 권한과 저장소 전체 접근 권한을 사용하지 않고, 광고 또는 분석 SDK를 포함하지 않습니다.

보관 및 삭제

개발자가 사용자 데이터나 변환 결과를 수집·보관하지 않습니다. 변환된 파일은 사용자가 기기의 파일 관리자에서 삭제할 수 있습니다.
