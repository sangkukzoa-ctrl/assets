ChatLens OCR v0.4.6 | Windows x64 | 무료 공개 테스트판
개발자: 2bornot · © 2026 2bornot · MIT License (원본 소스)

이 프로그램은 아직 개발 중이며 OCR 정확도가 안정화되지 않았습니다.
글자 오인식이나 문장 누락, 금액·날짜·표 항목의 오독이 발생할 수 있습니다.
중요한 내용은 원본 이미지와 대조하세요. 성능은 계속 개선 중입니다.

[다운로드 / 실행]
1. 공식 페이지: https://github.com/sangkukzoa-ctrl/assets/releases/tag/chatlens-v0.4.6
2. ChatLensOCR_v0.4.6.exe 파일을 직접 받거나, ZIP을 받아 압축 해제하세요.
3. EXE를 실행합니다. Python 설치나 인터넷 연결은 필요하지 않습니다.
4. 이미지 열기 또는 화면 붙여넣기 → 현재 이미지 분석 / 전체 이미지 일괄 분석.
5. 자동 모드부터 사용하고, 필요하면 쇼핑몰 목록·카카오톡·파판14·파일 탐색기 모드를 선택합니다.
6. 오른쪽 결과창에서 인식 결과를 직접 수정하고 TXT 또는 JSON으로 저장합니다.

[편리한 기능]
Ctrl+G: 카카오톡의 [글자 미인식] 표시로 이동
영역 분석: 미리보기에서 마우스로 분석할 부분만 드래그
미인식 찾기: 글자를 읽지 못한 부분으로 이동
디버그 로그: 오류 내용을 복사하거나 TXT로 저장
테스트결과 내보내기: 버전·날짜가 포함된 파일명으로 결과 TXT 저장

[개인정보 / 데이터]
인식은 로컬에서 진행되며 스크린샷이 외부 OCR 서비스로 자동 업로드되지 않습니다.
수동 학습 데이터와 디버그 로그는 %LOCALAPPDATA%\ChatLensOCR 아래에 저장될 수 있습니다.
프로그램 제거 시 EXE 파일을 삭제하면 됩니다. 앱 기록까지 지우려면 해당 폴더를
별도로 삭제하되, 보존할 데이터가 있다면 먼저 백업하세요.

[서명 / 무결성]
현재 Windows Authenticode 공인 코드서명이 없는 시험판이므로
Windows가 알 수 없는 게시자 또는 SmartScreen 경고를 표시할 수 있습니다.
공식 GitHub Release 주소와 SHA256SUMS.txt를 확인하세요.
빌드 출처 증명은 Windows 공인 게시자 서명과 다릅니다.

[알려진 문제]
- '오잉' → '으잉' 등 작은 한글 오인식
- '퉤' 같은 매우 짧은 메시지 인식 실패
- 쇼핑몰 가격·상품명, 파판14 직업아이콘/서버명/특수기호, 표 셀 혼동 가능성
- 모든 이미지/문자에 대한 100% 정확도 보장은 제공하지 않습니다.
