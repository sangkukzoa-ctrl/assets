[무료 배포 / 개발 중] ChatLens OCR — 오프라인 이미지·스크린샷 문자 인식 프로그램

현재 공개 테스트판: v0.4.7
운영 방식: 하루 1회 Windows 자동 빌드·회귀 검증, 검증 성공 시 동일 배포 주소 갱신
개발자: 2bornot
지원 운영체제: Windows x64

※ ChatLens OCR은 개발 중인 무료 공개 테스트판(Beta)입니다.
※ OCR 인식 성능이 아직 불안정하여 글자를 잘못 읽거나 문장 일부를 누락할 수 있습니다.
※ 특히 작은 한글 한 글자, 파판14 채팅의 특수 기호와 직업 아이콘, 복잡한 표·상품 목록에서 오류가 발생할 수 있습니다.
※ 정확도를 계속 개선 중이며, 중요한 문장은 반드시 원본 이미지와 비교해 주세요.

■ 개발 계기

파이널판타지14를 플레이하면서 대화 스크린샷을 문자로 옮기고 싶었고, 카카오톡과 쇼핑몰 상품 페이지에서도 같은 불편을 겪었습니다. 그래서 게임 전용 도구에서 시작해 범용 이미지 문자 인식 프로그램으로 확장한 것이 ChatLens OCR입니다.

사용자는 이미지를 열거나 스크린샷을 붙여넣고 [현재 이미지 분석] 또는 [전체 이미지 일괄 분석]을 누르면 됩니다. 별도의 Python 설치나 AI API 키는 필요하지 않습니다.

■ 주요 기능

· 일반 이미지, 스크린샷, 웹페이지, 쇼핑몰 상품 목록, 파일 탐색기 OCR
· 파판14 채팅·PvP 메시지·전투 로그·직업 아이콘 자동 판독
· 직업 아이콘 참고 자료 자동 확보 및 확신도가 높은 실제 아이콘만 로컬에 자동 학습
· 카카오톡 대화와 이미지 스티커 검출 및 등록된 스티커 재인식
· 한국어·영어·일본어 인식
· 화면 일부분을 드래그해 선택 분석
· 여러 장 일괄 처리
· TXT·JSON 파일 저장, 결과 직접 수정, 디버그 로그 및 테스트결과 내보내기
· [글자 미인식] 표시 찾기(Ctrl+G)

OCR과 학습 데이터 처리는 사용자 PC 내부에서 이루어지며, 스크린샷이나 대화 내용을 외부 인식 서버로 자동 전송하지 않습니다.

■ 사용 방법

1. 아래 GitHub 공식 배포 페이지에서 Windows 실행파일이나 ZIP을 다운로드합니다.
2. EXE를 실행하거나 ZIP을 압축 해제해 실행합니다.
3. [이미지 열기] 또는 [화면 붙여넣기]로 분석할 사진을 추가합니다.
4. [이미지 종류: 자동]으로 시작하고, 필요하면 파판14·카카오톡·쇼핑몰 등 전문 모드를 선택합니다.
5. [현재 이미지 분석]이나 [전체 이미지 일괄 분석]을 누릅니다.
6. OCR 결과를 원본과 대조하고, 필요한 부분을 수정한 뒤 TXT·JSON으로 저장합니다.

파판14 직업 아이콘은 사용자가 매번 직접 등록할 필요 없이 자동 인식합니다. 고신뢰 이미지 아이콘은 PC에 자동 축적되며, 수동 등록은 보조 기능입니다.

■ 알려진 문제와 개선 계획

일부 저해상도 이미지에서 문자 오인식이나 메시지 누락이 발생할 수 있습니다. 파판14 채팅이 JPEGView 같은 뷰어에 표시된 화면을 분석할 경우 주변 창 제목이나 다른 프로그램의 문자가 섞이는 문제가 확인되어, 화면 분리 처리를 개선하고 있습니다.

초기 내부 검증에서 카카오톡 정답 문장 16개 중 14개가 일치했지만, 해당 수치는 모든 스크린샷의 인식 정확도를 뜻하지 않습니다.

사용 중 문제가 발생하면 [디버그 로그]를 복사하거나 TXT로 저장할 수 있습니다. 개인 정보가 포함되지 않도록 확인 후 오류 상황을 제보해 주세요.
