[무료 배포 / 공개 테스트판] ChatLens OCR v0.4.6 — 이미지·스크린샷 문자 추출 프로그램 (Windows)

스크린샷에 있는 글을 복사하고 싶은데 직접 타이핑해야 하거나, 게임 채팅과 카카오톡 대화처럼 작은 글자가 많은 이미지를 정리하기 번거로웠던 적이 있습니다.

처음에는 파이널판타지14 채팅과 카카오톡 대화를 분석할 목적으로 개발했습니다. 이후 일반 스크린샷, 쇼핑몰 상품 목록, 파일 탐색기 등에도 쓸 수 있도록 기능을 확장했습니다.

그래서 개인적으로 개발한 Windows용 독립 프로그램 ChatLens OCR을 무료 공개 테스트판으로 배포합니다.

■ 먼저 알려드립니다 — 개발 중인 Beta입니다

ChatLens OCR은 아직 개발 중이며, 문자 인식 성능 역시 개선하는 과정에 있습니다.

화면의 글자 크기, 해상도, 글꼴, 배경색, 그림·이모티콘 등에 따라 글자를 잘못 읽거나 문장 일부를 놓칠 수 있습니다. 특히 짧은 한글 한 글자, 영숫자 혼합 표기, 복잡한 상품 목록과 표는 오류가 발생할 수 있습니다.

실제 테스트에서 ‘오잉’을 ‘으잉’으로 인식하거나 ‘퉤’를 제대로 인식하지 못하는 사례가 확인됐습니다. 개발 및 정확도 개선을 계속 진행 중입니다.

중요한 이름·금액·날짜·문장은 추출 결과를 원본 이미지와 한 번 더 비교해 주세요. 이 프로그램은 완성된 고정밀 상용 OCR을 표방하지 않습니다.

■ 주요 기능

• PNG·JPG·JPEG·WEBP·BMP·TIFF 이미지 열기
• 클립보드의 스크린샷 붙여넣기
• 이미지 한 장 또는 여러 장 일괄 분석
• 마우스로 필요한 부분만 드래그해 선택 영역 OCR
• 한국어 / 영어 / 일본어 OCR
• 이미지 종류별 모드: 자동, 범용, 쇼핑몰 목록, 카카오톡, 파이널판타지14, 파일 탐색기
• 결과 복사 및 TXT·JSON 파일 저장
• 카카오톡 발언자·이모티콘 및 파판14 채팅·서버명 등 전용 인식 기능
• [글자 미인식] 항목 찾기(Ctrl+G), 인식 결과 직접 수정
• 디버그 로그 복사·저장 및 테스트결과 TXT 내보내기

분석은 PC 내부에서 처리합니다. 이미지와 분석 결과를 외부 OCR 서버에 자동 전송하지 않으며, 별도의 AI API 키나 Python 설치도 필요하지 않습니다.

■ 사용 방법

1. 아래 GitHub 공식 다운로드 페이지에서 v0.4.6 Windows 파일을 받습니다.
2. ZIP을 받았다면 압축을 해제합니다. 또는 EXE 단독 파일을 받습니다.
3. ChatLensOCR_v0.4.6.exe를 실행합니다.
4. [이미지 열기]로 파일을 선택하거나 [화면 붙여넣기]로 스크린샷을 추가합니다.
5. [이미지 종류: 자동]과 [인식 언어: 한국어]에서 시작해 [현재 이미지 분석] 또는 [전체 이미지 일괄 분석]을 누릅니다.
6. 오른쪽 결과창의 내용을 확인합니다. 필요한 경우 글자를 직접 고친 후 [TXT 저장] 또는 [JSON 저장]을 이용합니다.

드래그로 작은 영역만 분석할 수도 있습니다. 파판14·카카오톡 전용 기능은 해당 이미지 종류를 선택하면 사용할 수 있습니다.

■ 개발 및 사용 시 참고

현재 8차까지의 내부 개선·검증을 진행했습니다. 평가용 카카오톡 문장 16개 중 14개가 정확히 일치했지만, 이 값이 모든 이미지의 인식 정확도를 뜻하지는 않습니다. 인식 실패 사례가 여전히 남아 있으며 지속적으로 개선할 계획입니다.

실행파일에 Windows 공인 코드서명(Authenticode)은 아직 적용되지 않았습니다. 따라서 Windows에서 알 수 없는 게시자 또는 SmartScreen 경고가 표시될 수 있습니다. 배포 출처는 위 GitHub 공식 주소로 확인해 주세요.

프로그램의 원본 애플리케이션 소스는 MIT 라이선스로 공개하며, 게임·메신저의 상표 및 제3자 라이브러리의 권리는 각 권리자에게 있습니다.

문제가 발생하면 프로그램의 [디버그 로그]에서 관련 내용을 복사·저장할 수 있습니다. 오류를 제보하실 때는 개인정보가 포함되지 않도록 확인해 주세요.
